- **Source:** supplied by the project owner in `D:\Jazztor\upgrade v1 pics` on 2026-10-20.
- **Origin (confirmed 2026-11-02):** all seven files are AI-generated images, made by the project owner in their own
  ChatGPT (OpenAI) account. Each original carries an OpenAI C2PA content credential (checked 2026-11-02: a `c2pa` /
  JUMBF manifest naming OpenAI / ChatGPT). They are not photographs and have no third-party author.
- **Rights:** OpenAI's terms assign output to the user who generated it, commercial use included; no attribution is
  owed. Purely AI-generated images are generally not copyrightable (e.g. in the US), so the project cannot stop others
  reusing them.
- **Disclosure:** the app's Credits state that the window view and the room's material textures are AI-generated, so
  the Toronto view is never presented as a real photograph.
- The three Toronto frames are pixel-aligned (measured offset 0,0), which the renderer relies on for crossfades.
- Resolution is below the manifest's 6000 px master requirement; see `reports/` for the effect at 4K.
